# Round Archive

Closed rounds live here.

Archives preserve:
- objective;
- required agents;
- tasks;
- important forum conclusions;
- promoted permanent decisions;
- commits/handoffs;
- Germinator QA result;
- Gonza release result;
- deferred items;
- `ROUND_COMPLETE` closure.

Historical instructions must stay here rather than in active surfaces. A new round must never infer current work from an archive.
