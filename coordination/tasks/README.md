# Active Tasks

This directory contains task contracts for the current round only.

Every real task must define:
- ID;
- round;
- owner;
- goal;
- dependencies;
- allowed files/subsystems;
- prohibited scope;
- collaborators/reviewers;
- acceptance criteria;
- tests/evidence;
- related forum threads;
- current status.

Agents may not silently expand scope. New discoveries are raised in the forum and assigned by Neureon.

When no round is active, this directory contains only this README.
