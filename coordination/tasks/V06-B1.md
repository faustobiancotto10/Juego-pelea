`TITLE/COVER → FIGHTER SELECT → OPPONENT SELECT → STAGE SELECT → VS → FIGHT → RESULT`

## Required

Title:
- cover/title presentation;
- dominant `COMENZAR`;
- secondary `CONTROLES`.

Fighter select:
- Camaleoni, Supernariz, Juanchi;
- compact scalable roster presentation;
- strong selected state + info panel;
- no hardcoded two-fighter layout;
- metadata-only 5/10-entry fixtures.

Stage select:
- existing stage + Cancha 56;
- preview/name/confirm/back;
- match setup owns selected stage.

VS:
- exact selected fighters + stage;
- brief presentation transition.

Fight/result:
- current controls grammar;
- Juanchi ball availability state;
- rematch retains fighter/stage;
- back/change flows reset input safely.

- fifth action button;
- UI determining combat legality;
- dashboard/e-commerce card look;
- hidden two-roster assumptions.

- no stuck pointer/input through navigation;
