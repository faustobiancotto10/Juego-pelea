## Mission

Bring Camaleoni and Supernariz to the same higher reference-fidelity and procedural-detail standard as the human fighters so the roster does not become visually uneven.

## Own

- `src/game/render/ChameleonRig.ts`;
- `src/game/render/SupernarizRig.ts`;
- fighter-specific detail helpers created solely for these two fighters;
- corresponding portrait-specific implementation only where compatible with the shared PortraitRenderer contract.

Shared architecture files belong to Mario-A. Motion/effects shared files belong to Mario-D.

## Required work

### Camaleoni
Preserve and improve the intentionally non-human silhouette:
- oversized human head;
- long scaled neck;
- reptile body;
- claws;
- readable scale field/material;
- spiral tail;
- richer face/hair/skin treatment while retaining gameplay readability.

### Supernariz
Increase reference fidelity and material richness:
- canonical long bulbous nose;
- distinctive human proportions and stance;
- blue/red superhero suit with layered texture/shading;
- cape construction and readable volume;
- chest nose emblem;
- belt/sausage props and other canonical cues;
- face/head silhouette that cannot collapse into a generic fighter head.

## Gates

Both fighters must pass:
- neutral silhouette separation from each other and from Juanchi/El Toro;
- identity/reference comparison;
- gameplay-scale readability;
- no raster/reference runtime assets.
