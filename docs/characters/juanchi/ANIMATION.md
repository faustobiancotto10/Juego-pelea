# Juanchi Animation Contract

Authoritative shared standard: [V0.6 animation-quality contract](../../superpowers/specs/2026-09-20-v06-animation-quality-contract.md).

Visual authority: [PACKAGE](PACKAGE.md) and files under `references/`.

## Permanent rule

Every action must communicate preparation, force production/contact and recovery through the articulated body. Root translation alone is invalid.

## Locomotion

Juanchi must have:
- weight-shift start;
- forward gait with planted support;
- distinct shorter/braced backward gait;
- stop blend;
- dash compression/drive;
- visible jump preparation;
- takeoff, ascent, apex, descent brace;
- landing absorption.

The ball-holding arm remains naturally constrained while the free arm counterbalances.

## Moves

- Jab: shoulder/hip impulse, fist extends, recoil.
- Shoulder: visible load and body drive; cannot look like a sliding idle pose.
- Low: lower-body level change with planted support.
- Air: airborne attack silhouette remains distinct from neutral jump.
- Boomerang: hand carries available ball, throw has windup/release/follow-through; arm is empty while ball is in flight.
- Fricción: hands meet/braced knees → alternating friction beats → whole-body palm release → recovery. Restrained sparks support, never replace, hand action.
- Police Cap Rage: belt retrieval → windup → cap launch → recognition/rage → rush → multi-hit → finisher. Cap state must be mutually exclusive.

## Text/readability

`La 56` on the shirt must not become mirror-reversed local text when fighter facing changes; author drawing accordingly.

Effects-disabled fixtures must still make Boomerang throw, Fricción final palm and Ultimate finisher recognizable.
