# Juanchi Gameplay

Authoritative numeric contract: [Juanchi V0.6 contract](../../superpowers/specs/2026-09-20-v06-juanchi-character-contract.md).

Archetype: mid-range aggressive / space manipulation.

Core loop:
1. create a lane with Rugby Boomerang;
2. reposition so the return path matters;
3. convert respect into jab/shoulder, low or committed Fricción;
4. use Police Cap Rage as a readable committed capture Ultimate.

Strengths:
- two-pass returning projectile;
- movement changes return geometry;
- close pressure when opponent respects ball;
- expressive 190-damage Ultimate.

Weaknesses:
- one ball only;
- clean interruption removes it;
- shorter outbound control than Lengua;
- visible turn/rearm gap;
- Fricción is committed and escapable;
- cap Ultimate is avoidable before capture;
- no armor, custom resource, double jump or air Special.

Initial stats:
- HP 1000
- walk 4.55
- jump 12.2
- gravity 0.73
- hurt size 56×120

Universal guard, dash, Push Guard and SUPER rules remain unchanged unless the V0.6 system contracts explicitly modify them.
