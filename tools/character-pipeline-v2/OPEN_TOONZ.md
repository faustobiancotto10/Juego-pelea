# OpenToonz — optional authoring lane

OpenToonz is permitted only as an external authoring/motion-study tool.

Use it when a cutout/pose/timing study is materially easier there than in Synfig or the in-repo renderer.

Do not:
- make OpenToonz a runtime dependency;
- commit generated raster fighter sprites as the gameplay representation;
- replace procedural articulated Canvas2D fighters with exported stickers.

Any useful timing, pose, silhouette or deformation lesson must be translated back into the procedural rig implementation and its tests/evidence.
